# НИЙТ.мн

**Уриа:** Өдөр бүр хэрэгтэй бүх зүйл.

Монголын өдөр тутмын бараа, үйлчилгээ, мэдээлэл, бизнесийн хэрэгцээг нэг дор холбох нэгдсэн платформ.

## Брэнд ба интерфэйс
- Баталсан дизайн: **4 — Bold**
- Хар premium суурь, алтлаг шар акцент
- Mobile-first responsive загвар
- Нүүр хуудасны зургаан үндсэн хэсэг: Өнөөдрийн хямдрал, Үйлчилгээ, Өнөөдрийн мэдээлэл, Хоол/ресторан, Бизнес, Өнөөдөр хаана юу болох вэ?

## Frontend хуудсууд
- `index.html` — нүүр хуудас; баталгаажсан бизнес, хүчинтэй хямдралын мэдээллийг Supabase-ээс татна; Open-Meteo цаг агаар, ExchangeRate-API ханш, Google Maps traffic холбоос
- `auth.html` — и-мэйл/нууц үгээр бүртгүүлэх, нэвтрэх, нууц үг сэргээх
- `account.html` — хэрэглэгчийн хувийн самбар, өөрийн зар, бизнес, төлбөрийн төлөв
- `submit.html` — зар оруулах, зураг upload хийх, админы хяналтад илгээх
- `business-form.html` — бизнес бүртгүүлэх, лого upload хийх
- `businesses.html` / `business.html` — баталгаажсан бизнесийн лавлах болон дэлгэрэнгүй
- `deal-form.html` / `deals.html` — бизнесийн хямдрал, купон оруулах болон хүчинтэй саналуудыг харах
- `payment.html` — шилжүүлгийн баримт илгээх (автомат төлбөр биш)
- `admin.html` — зар, бизнес, төлбөрийн хяналт; платформын суурь хураамжийн тохиргоо
- `setup-admin.html` — анхны админыг нэг удаагийн түлхүүрээр аюулгүй идэвхжүүлэх
- `categories.html` — 12 үндсэн ангилал, 80 орчим дэд ангилал
- `listings.html` / `listing.html` — ангилал, хайлт, эрэмбэлэлт, баталгаажсан зарын жагсаалт ба дэлгэрэнгүй
- `404.html` — олдсонгүй хуудас

## Backend ба хамгаалалт
- Тусдаа Supabase project: `oyxvjatfuqzukdrdlvfb` (ap-southeast-2)
- Supabase Auth: и-мэйлээр бүртгүүлэх/нэвтрэх, password reset
- PostgreSQL хүснэгтүүд: `profiles`, `listings`, `businesses`, `deals`, `payments`, `app_settings`, `admin_audit_logs`
- Зар, бизнес, хямдралын мэдээлэл эхлээд `pending` төлөвтэй; админ баталгаажуулсны дараа нийтэд харагдана
- Row Level Security: эзэмшигч өөрийн мэдээллээ удирдана; нийтэд зөвхөн баталгаажсан мэдээлэл харагдана; админы үйлдэл хамгаалалттай RPC-ээр бүртгэгдэнэ
- Storage: `niit-uploads` public read, authenticated owner-folder upload, JPG/PNG/WEBP, 5 MB лимит
- Төлбөрийн баримт хадгалах, админ шалгах урсгал бий; автомат банк/картын gateway хараахан холбогдоогүй
- Админ эхний тохиргоо нь нэг удаагийн, хугацаатай токеноор хийгдэнэ
