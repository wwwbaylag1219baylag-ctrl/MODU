# НИЙТ.мн

**Уриа:** Өдөр бүр хэрэгтэй бүх зүйл.

Монголын өдөр тутмын бараа, үйлчилгээ, мэдээлэл, бизнесийн хэрэгцээг нэг дор холбох нэгдсэн платформ.

## Батлагдсан брэндийн чиглэл
- Дизайны сонголт: **4 — Bold**
- Хар бараан premium суурь, алтлаг шар акцент
- НИЙТ.мн лого болон алтлаг үндсэн үйлдлийн товч
- Хотын панорама төрхтэй нүүр хуудасны гол хэсэг
- Өдрийн онцлох санал, цаг агаар, валютын ханшийн блокууд
- Өнгөлөг үйлчилгээний ангилал, бизнесийн танилцуулга
- Mobile-first, tablet болон desktop-д зохицох responsive загвар

## Одоогийн хувилбар
- `index.html` — Bold загварын нүүр хуудас; 6 үндсэн хэсэг: Өнөөдрийн хямдрал, Үйлчилгээ, Өнөөдрийн мэдээлэл, Хоол/ресторан, Бизнес, Өнөөдөр хаана юу болох вэ?
- `categories.html` — 12 үндсэн ангилал, 80 орчим дэд ангилал; дэд ангилал бүр жагсаалтын хайлт руу холбогдсон
- `listings.html` — ангилал шүүх, түлхүүр үгээр хайх, үнийн дарааллаар эрэмбэлэх responsive жагсаалт
- `listing.html` — сонгосон зар/бараа/үйлчилгээний дэлгэрэнгүй хуудас
- Жагсаалт болон дэлгэрэнгүй хуудасны 9 ширхэг жишээ мэдээлэл (бодит зар биш; backend холбогдоогүй)
- Гар утасны цэс
- Хэрэглэгчид зориулсан танилцуулга, бизнесийн CTA болон онцлох бизнесүүдийн хэсэг
- Үндсэн зургаан хэсгийн карт, responsive 6/3/2 баганат зохион байгуулалт
- Цаг агаар болон валютын хэсгүүд UI placeholder; бодит өгөгдлийн эх сурвалж хараахан холбогдоогүй

## Дараагийн хөгжүүлэлтийн шат
1. Ангилал, дэд ангиллын өгөгдлийн бүтэц
2. Бараа, үйлчилгээ, бизнесийн дэлгэрэнгүй хуудас
3. Хэрэглэгч болон бизнесийн бүртгэл/нэвтрэлт
4. Админ удирдлага
5. Өгөгдлийн сан, хайлт, төлбөрийн урсгал

**Төслийн тусгаарлалт:** НИЙТ.мн нь Угалз.мн-ээс бүрэн тусдаа репозитор, код, өгөгдөл болон бүтээгдэхүүн байна. Угалз.мн-ийн файлууд, тохиргоо, домэйнд өөрчлөлт хийхгүй.
