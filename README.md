# НИЙТ.мн

**Уриа:** Өдөр бүр хэрэгтэй бүх зүйл.

НИЙТ.мн нь Монголын хэрэглэгчдийн өдөр тутмын бараа, үйлчилгээ, мэдээлэл, бизнесийн хэрэгцээг нэг дороос холбох нэгдсэн платформын төсөл юм.

## Одоогийн хувилбар
- Responsive нүүр хуудасны эхний хувилбар
- Нэгдсэн хайлтын интерфэйс (одоогоор демо)
- Үндсэн ангиллын танилцуулга
- Бизнес эрхлэгчдэд зориулсан танилцуулга

## Файлууд
- `index.html` — нүүр хуудасны эхний хувилбар

## Хөгжүүлэлтийн тэмдэглэл
Энэ хувилбар нь урд талын загварын суурь юм. Хайлт, хэрэглэгчийн бүртгэл, бизнесийн бүртгэл, өгөгдлийн сан, админ удирдлага болон төлбөрийн урсгал хараахан холбогдоогүй.

**Төслийн тусгаарлалт:** НИЙТ.мн нь Угалз.мн-ээс тусдаа репозитор, тусдаа код болон тусдаа бүтээгдэхүүн байна. Угалз.мн-ийн файлууд, тохиргоо, домэйнд өөрчлөлт хийхгүй.
